4. **R4/R7**：命令生命周期 + 幂等在 `command_ledger`，不在 `run_command`（文档误判已改）。
5. **R8**：`UPDATE run … SET … status='paused'`（run 侧）只在 `ExperimentProjectorMapper.xml`。
   判据是**正则 + 全部 mapper XML 全量扫描**（`ExperimentStateProjectorSelfTest` §5b）：
   等号无空格 / 多空格 / 跨行 / 大小写 / 表别名都能识别，且**新增 mapper 直写会红**；
   `… WHERE status='paused'`（只作查询条件）不误报。

## 6. R12 自动路径语义（评审澄清）

**自动卸载路径（settle / BatchOrchestrator）只发「请求卸载」（loaded→unloading，位置仍占用）**，
**确认卸载（unloading→unloaded + 清位置）由人工端点 `POST /experiment-runs/{runId}/confirm-unload` 收口**
（未来设备卸载命令回报后可自动确认）。这不是半截，是「卸载=确认后清位置」的两段式——
实验结束板仍物理在设备上，位置本就不该自动清空。
