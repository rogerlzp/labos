# 05 · 异常恢复与并发验收（第一版 · 问题清单）

> 设计要求：`runtime-consistency/05`（恢复=对账，不是推断）。

## 5.1 恢复协议

| 问题 | 设计要求 | 当前实现 | 证据 | 判定 |
|---|---|---|---|---|
| 重启对账在途命令 | 非终态命令逐条查询 | rehydrate 只恢复队列 + 清扫泄漏锁，不对账命令 | `rehydrateQueued` / `sweepExpiredLocks` | **GAP** |
| 重启对账物料位置 | 非 KNOWN 板走盘点 | 无 | — | **GAP** |
| 泄漏锁回收 | 过 TTL 回收，不误删他人 | `sweepExpiredLocks`（删自己占的） | PASS | PASS |
| 断连后对账 | 恢复上线先对账最后命令 | 设备恢复心跳即自动恢复 `paused_fault`，不对账命令 | `autoResumeFaulted` | PARTIAL |

## 5.2 并发与幂等

| 问题 | 设计要求 | 当前实现 | 证据 | 判定 |
|---|---|---|---|---|
| 命令幂等 | `command_id` 去重 | 幂等键有雏形，无独立 command_id | `run_command` 幂等键 | PARTIAL |
| 多实验并发抢设备 | 资源级互斥 | `resourceHolds` + `DeviceLock` | `ExperimentScheduler` | PASS |
| 死锁 | 升序加锁 + 等待图 | `PositionLock` 双锁升序 + `WaitForGraph` | `TransferPlan` / `WaitForGraph` | PASS |
| 事务回滚 | 暂停/释放同事务 | P-06 V2 单事务 | `PauseManager.pauseTx` | PASS |

## 5.3 结论

- 核心 GAP：**重启/断连后没有「对账在途命令 + 物料位置」的步骤**——恢复依赖内存残留推断。
- 这是实现期第三批（异常恢复）：重启对账协议 + 命令状态持久化（配合 03）。
