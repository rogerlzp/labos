## 6. 怎么判断"现在有几个窗口在动"

```bash
# ① 谁在改文件（最近 10 分钟被写过的源文件）
find . -path ./.git -prune -o -type f -newermt '-10 minutes' -print \
  | grep -vE "node_modules|/out/|\.class$|obj/|bin/|\.log$"

# ② 文件是否还在被写（隔 60 秒比 md5，不一致 = 正在写）
md5 -q labos-kernel/src/main/java/com/labos/kernel/workflow/WorkflowService.java; sleep 60; \
md5 -q labos-kernel/src/main/java/com/labos/kernel/workflow/WorkflowService.java

# ③ 跑着几个环境
lsof -nP -iTCP -sTCP:LISTEN | awk '{print $1, $9}' | sort -u

# ④ 已提交的归属（看内容，不看作者——多窗口共用同一 git 身份）
git log --oneline -10
```

判断经验：`git status` 两次之间**文件数在长** = 对面还在写；`md5` 连续 60 秒不变
且 `build-kernel.sh` + `test-all.sh --pure-only` 双绿，才是可提交时点。
