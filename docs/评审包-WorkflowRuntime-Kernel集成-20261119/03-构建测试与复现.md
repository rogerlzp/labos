# 03 — 构建、测试与复现

## 1. 本地标准构建

在仓库根目录：

    ./scripts/compile-kernel.sh

预期步骤：
1. ensure-deps.sh 准备 Maven 和 Kernel 依赖；
2. workflow-runtime Maven install；
3. Runtime JAR 复制到 labos-kernel/lib/spring/；
4. javac 编译 Kernel src/main + src/boot；
5. XML 资源合法性检查；
6. Mapper / 配置资源同步到 labos-kernel/out。

本仓库历史构建并非 Maven Reactor；不要擅自把 Kernel 的既有构建改成 Maven package，除非能覆盖全部旧测试/启动脚本并给出证据。

## 2. Runtime Maven 测试

Kernel 纯逻辑测试中新增 Runtime smoke test，输出格式遵循 `test-all.sh` 的 `通过 N / 失败 M` 门禁解析契约。

只运行纯单元测试：

    mvn -B -f workflow-runtime/pom.xml test

PostgreSQL 17 集成测试（需要数据库环境变量）：

    RUN_RUNTIME_PG_IT=1 PGHOST=localhost PGPORT=5432 PGUSER=runtime PGPASSWORD=runtime PGDATABASE=runtime_test mvn -B -f workflow-runtime/pom.xml test

CI 工作流 .github/workflows/workflow-runtime-db.yml 会：
- 启动 PostgreSQL 17；
- 初始化 db/workflow_runtime/001_init.sql；
- 执行 schema contract；
- 执行双会话并发与 CON-01..14；
- 执行事务原子性 / Inbox 冲突；
- 执行 Java Repository 集成测试。

## 追加：Kernel 装配与 Mapper 参数测试

1. 建立 AnnotationConfigApplicationContext，注入一个 DataSource 和一个 PlatformTransactionManager；
