# 01 — 架构与决策边界

## 1. V1 部署拓扑

    LabOS Kernel Spring Boot JVM
      ├── Existing Kernel services / MyBatis mappers
      ├── Existing Hikari DataSource (single pool)
      ├── Existing PlatformTransactionManager (single manager)
      └── Embedded workflow-runtime JAR
            ├── WorkflowRuntimeRepository
            ├── WorkflowDefinitionSource adapter port
            ├── BPMN GraphPlan compiler
            └── WorkflowRunFactory

    PostgreSQL 17
      ├── Existing Kernel tables: workflow / workflow_node / workflow_edge
      └── workflow_runtime schema: snapshots / runs / tokens / attempts / inbox / outbox ...

Runtime is a separate build module, not a separate process/service.

## 2. BPMN 与 GraphPlan 职责

- BPMN XML（workflow.graph->>'xml'）是控制流语义权威来源。
- workflow_node 是节点身份/能力/设备绑定等关系型元数据投影。
- workflow_edge 不是完整 BPMN 投影；当前不保存完整 sequenceFlow id、conditionExpression、gateway default，禁止用它反向重建 GraphPlan。
- GraphPlan 是编译后的不可变执行表示，不保存 Run 实时状态。
- Run 创建时保存 GraphPlan JSON snapshot；Run 恢复必须读取该 snapshot，不得读取当前最新 BPMN 覆盖旧定义。

## 3. 租户身份

- Kernel legacy tenant id 是 bigint。
- Runtime tenant_id 是 UUID。
- 唯一允许的桥接 key 是稳定 tenant_key：kernel-tenant:<positive bigint>。
- 不允许 bigint cast UUID，不允许每次启动随机生成 Runtime UUID。
- GraphPlan definitionKey 还应包含 Runtime tenant UUID，避免不同租户 workflow id 冲突。

## 4. 事务边界

- Kernel DataSourceConfiguration 创建唯一 Hikari DataSource 和唯一 DataSourceTransactionManager。
- WorkflowRuntimeKernelConfiguration 必须注入上述两个 Bean。
- WorkflowRuntimeRepository 的写事务和 snapshot 只读事务都必须使用同一个传入 PlatformTransactionManager。
- 禁止 Repository 在 Kernel 集成路径自行 new DataSourceTransactionManager。
- Repository 和 MyBatis 使用同一 DataSource，因此处于同一个 Spring 事务时必须加入同一线程绑定连接。
- BPMN 定义读取专门使用 `REQUIRES_NEW + REPEATABLE_READ + readOnly`，确保 Header、原始 XML、node metadata 来自同一数据库快照；Header 和 XML 查询排除软删除流程。
- Runtime metadata 查询同时限定 workflow_node tenant/workflow，并要求 capability join 的 tenant_id 与 node tenant_id 一致。

## 5. 单实例化边界

保留：数据库事务、行锁、唯一约束、CAS、Outbox、Inbox 去重、设备资源占用业务事实、UNKNOWN / MANUAL_REQUIRED / QUARANTINED。

移除/不实现：多实例 Coordinator 竞争、DB Worker Lease、Leader Election、跨节点 fencing、分布式 Recovery。

## 6. 当前阶段明确不包含

- GraphCoordinator 的图状态推进。
- 条件表达式求值。
- 完整 Parallel/XOR/Inclusive Split/Join 运行语义。
- EventIngress / OutboxDispatcher / Adapter / EventDispatcher 运行闭环。
- Mock E2E、故障注入、真机 readback。
- 生产流量迁移或旧 GraphRunner 下线。
