# 07 · 两套暂停模型合并方案（R8 · 第二版 · 按评审 6 点修订）

> 第一版方向认可，本版按评审 6 点修订现状前提、复用、事实/投影定性、迁移判据、
> 词表前置、验收标准。**修订后即可开工，先做步骤 1（抽纯函数 + 投影比对）。**

---

## 1. 现状（修订前提）

- **`RunControl` 已不直写 `paused`**：只写 `control_state=PAUSE_REQUESTED` + Hold；
  收敛由 `ExperimentExecutor.settle`（动作边界）/ `convergeQueuedPauses`（排队）做。
- **真正还直写 `status='paused'` 的只剩 `run` 侧 `PauseManager`**（workflow run）。
- 已有组件：`PauseCoordinator`（ADR-PAUSE-007 统一适配层）、`ExperimentStateProjector`（S-03 单写者）、
  `StatusVocabulary`（词表 + CASE SQL）。
- **`RuntimeHold`** 是真正的阻断事实；`control_state` 是**中控的意图状态机**，不是物理事实。

## 2. 事实 vs 投影（修订定性）

| 层 | 定性 | 内容 |
|---|---|---|
| 事实 | 物理/设备 | `runtime_hold`（扣留）+ L4 设备回包/物理确认 + R3 的 `reconciliation_required`（异常分支：物理不确定） |
| 意图 | 中控 | `control_state`（PAUSE_REQUESTED/PAUSING/RESUMING）——**不是事实**，是请求状态机 |
| 投影 | 由事实推导 | `run.status` / `experiment_run.status`（「设备确认已停」才写 paused；不确定写 manual/PauseUnknown） |

> **关键澄清（评审第 3 点）**：R3 实装的是**异常分支**（`reconciliation_required → manual` 转人工），
> 不是「设备确认已停」的正向信号。投影器不能拿「请求」当「物理事实」。

## 3. 复用与不新建（评审第 2 点）

- **不新建 `PauseProjector` 类**（避免重复造轮子）——**扩展 `ExperimentStateProjector`**（S-03 单写者），
  在其中加一个**纯函数 `resolvePauseKind(requestedKind, hasReconciliationRequired)`**，
  由 `ExperimentExecutor.settle` 调用（把 R3 的 override 逻辑收口进单一纯函数）。
- `PauseCoordinator` 已是统一适配层，不动它的职责；`StatusVocabulary` 词表保持单一真源。

## 4. 迁移步骤（修订版，5 步）

| 步 | 内容 | 判据（修订） |
|---|---|---|
| 1 | **抽纯函数 `resolvePauseKind`** + 用它替换 `settle` 里的 R3 override + 纯自测 + 「投影器输出 vs 落库状态」比对自测 | 投影输出 = 落库状态（每步重新归零） |
| 2 | **统一 `pause_kind` 词表前置**：`RuntimeHold.Kind` 为唯一真源，`PauseManager.Kind` 收为别名（兼容层在步骤 1 就位） | 两套 code 兼容、无漂移 |
| 3 | `PauseManager` 的 `run` 侧暂停路径切到投影器（写 `runtime_hold` + `control_state`，不再直写 `run.status`） | 投影输出 = 落库状态 |
| 4 | 删直写点 + 加 feature flag（`LABOS_PAUSE_PROJECTOR` 开关，可回滚） | flag 关=旧路径、开=投影器，各跑一轮回归 |
| 5 | `resume` 对称路径（01 §2 `ResumeRequested/ResumeUnknown`）落点 + 三层一致性回归 | 暂停→恢复全链路一致 |

> **迁移期间保护 R3**：`PauseUnknownDbSelfTest`（含反例）每步都跑，改的是同一个 `settle` 写入口。

## 5. 验收标准（修订补全）

1. 暂停→恢复全链路：`runtime_hold` + `control_state` + 两张 status 三者**最终一致**（判据：暂停后 settle 完，三者都反映「已停/不确定」，不出现一边 paused 一边 running）。
2. `grep` 全仓无投影器之外的 `status='paused'` **及 `pause_kind`/`paused_at`/`pause_reason`/`control_state`** 直写。
3. 既有 `RunControlDbSelfTest` / `PauseCoordinatorDbSelfTest` / `PauseUnknownDbSelfTest` / `BatchDbSelfTest` 全绿。
4. feature flag 开/关各一轮回归，diff 归零。

## 6. 本方案不做什么

- 不合并 `run` 与 `experiment_run` 两张表。
- 不动命令生命周期（`command_ledger`，R4）。
- 不新增功能。
