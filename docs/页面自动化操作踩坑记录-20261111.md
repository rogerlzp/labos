Playwright e2e 脚本（逐步等待 + 截图自检 + DB 终验）是可行的正解，成功搭完

## 上午：手动 CDP 为什么不行（实测记录）

bpmn-js 画布对指针事件非常敏感，合成事件与真实鼠标事件在时序、目标元素判定上
有系统性差异，操作结果不可控：

1. **press + move + release 语义不稳定**
   - 手型工具下，一次"拖拽平移画布"的操作被画布判定为**点击**，结果在默认位置
     (516,547) 凭空新建了一个并行网关。原因：之前激活的"网关工具"并未退出，
     canvas press 被解释为"放置元素"。
   - 也就是说：**任何一次 canvas press/release 都可能是"放置工具元素"**，而
     工具是否处于激活状态无法从 DOM 稳定判断（`.highlighted-entry` 经常缺失）。

2. **点击选不中元素**
   - 对网关中心点连续多次 press/release + hover 前置 move，元素始终不进入
     `.selected` 状态；合成事件经常只触发 hover。

3. **工具不自动退出，产生级联污染**
   - 点击 palette 上的工具图标后，工具保持激活。此后每一次画布点击都会
     新建同类元素（拖 midpoint 也会新建网关）。

4. **错误会静默落库**
   - 画布改动触发 draft 保存，错误创建的网关直接持久化到 `workflow_node` 表，
     页面上看不出来，只能靠 SQL 核对才能发现"画布上多了个东西"。

5. **会话频繁过期放大损失**
   - 页面会话约 15–30 分钟过期，过期后 draft 保存静默失败并跳登录页，
     前面做对的操作可能整段丢失。

## 下午：Playwright 脚本可用的前提 —— 六个必须绕开的坑

范例脚本：`scripts/e2e-wire-flow-c.py`（坑都写进了注释）。

1. **connect 工具连的线不落库**：前端只把它标脏（`commandStack.changed`），
   只有 palette 拖入 / 「删除选中节点」/ 点「保存」才持久化（Designer.tsx 实测）。
   → 连线只能验画布计数，最终靠「保存」+ 服务端校验 + DB 终验把关。
2. **从网关 diamond 拖线会被当成移动元素**（drag 手势静默无效）；
   **click-click（点源→点目标）稳定可用**。
3. **叠放的两个同坐标元素，点击永远命中上层**（z-order），下层会被当成
   「孤立节点」拒绝保存 —— 保存报错里的孤立节点就是下层网关。
   → 先拖开上层（选中→拖拽）再连线。
4. **页面有多个「保存」按钮**（画布头 / 流程选项面板），
   `get_by_role("保存").first` 可能点错（点了选项保存 = 静默无效）。
   → 取与「自动对齐」同排的那个。
5. **画布平移用手型工具拖空白处即可**；工具残留激活时 canvas 点击会新建
   元素 —— 每步先点手型工具退出并验证 `highlighted-entry`。
6. SVG path 端点提取（getScreenCTM）拿到的矩阵不可靠，别用它做端点校验。

## 可靠路径排序

- **Playwright e2e 脚本**（`scripts/e2e-wire-flow-c.py` 为范例）；
- 人工在页面上操作；
- 直接调用内核 API/数据库造数（此前流程 A 的 API 造数方式稳定可用，
  仅在最终需要"页面上可见"时人工微调）。
