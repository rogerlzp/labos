## 每个模块设计文档的统一结构

新建模块文档时按这 7 节写，缺一节就写"待补"，不要省略：

| 节 | 内容 |
|---|---|
| 1 职责与边界 | 这个模块管什么，**不管什么**（边界比职责更重要） |
| 2 数据模型 | 涉及的表、关键字段、外键、枚举取值 |
| 3 接口契约 | API 列表 + 请求/响应类型（与 `webapp/src/api/client.ts` 同步） |
| 4 状态与流程 | 状态机 / 流程图 / 时序 |
| 5 错误码 | 本模块产生的错误码与处置建议 |
| 6 并发与事务 | 谁会并发写、要不要锁、失败怎么回滚 |
| 7 已知问题 | 待办、缺陷、有争议的设计 |
