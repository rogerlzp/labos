## 核查方法

- 固定在核查基线 commit 上读取 Git tree、源码、Mapper XML、数据库迁移和测试文件。
- 从真实调用链核对，不以类名、文档标题或测试数量推断能力已完成。
- 将源码实现、自动化测试、模拟环境证据、真实设备现场证据分开。
- 结论采用 PASS / PARTIAL / FAIL / UNKNOWN；PARTIAL 不得对外描述为完成。
- 关键结论均给出仓库内文件路径及行范围，行号对应核查基线。

## 重要边界

- 本轮通过 GitHub 源码读取完成静态核查；未在用户的本地设备环境运行构建、数据库自测或真实设备流程。
- 核查时 GitHub commit status 未返回任何状态检查记录，因此不声明本轮 CI 通过。
- 真实设备现场日志、传感器/扫码原始证据和客户验收记录未在本轮材料中，因此物理闭环结论为 UNKNOWN。
