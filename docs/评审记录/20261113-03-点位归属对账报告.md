**列说明**

- `res` = `resource_node.id`（设备节点）；`inst` = `device_instance.id`。
- `点位` = `parent_id = res` 且 `kind ∈ (incubator, storage, transfer_point)` 的子节点数。
- `配置` = `device_point` 行数；`状态行` = `position_state` 行数；
  `rp` = `robot_point` 行数（**全部 `fill_status='pending'`，x/y/z 为空**）；
  `port` = `device_port` 行数（13 台全为 0）。
- 型号来自 `device.name`（通过 `device_instance.device_id`），仅供参考，
  **型号名里的数字（如 Hotel12H）不等于点位数**，没有据此推断。

**② 列建议写法**（一行一个点位，可只写与默认不同的项）：

```
P1:both/可达; P2:both/可达
P1:entry/可达; P2:exit/可达; P3:internal/不可达
```

角色取值：`entry`（进口）/ `exit`（出口）/ `both`（既是进口也是出口）/ `internal`（设备内部位，机械臂不可达）。
不填的默认口径是「`both` + 可达」——**这是当前 13 个已有点位的口径，不是现场确认过的口径**。

## 6. 复现 SQL（全部只读）

```sql
-- 岛下 13 台设备
SELECT id, code FROM resource_node
 WHERE tenant_id=1 AND parent_id=1000005 AND kind='device' ORDER BY code;

-- 每台设备点位数 / 配置 / 状态行
SELECT d.code, count(r.id), count(dp.id), count(ps.resource_id)
  FROM resource_node d
  LEFT JOIN resource_node r ON r.parent_id=d.id AND r.tenant_id=d.tenant_id
       AND r.kind IN ('incubator','storage','transfer_point')
  LEFT JOIN device_point dp ON dp.point_resource_id=r.id AND dp.tenant_id=r.tenant_id
  LEFT JOIN position_state ps ON ps.resource_id=r.id AND ps.tenant_id=r.tenant_id
 WHERE d.tenant_id=1 AND d.parent_id=1000005 AND d.kind='device'
 GROUP BY d.code, d.id ORDER BY d.code;

-- legacy 归属映射
SELECT r.attr->>'equipment_instance_id' AS eid, count(*),
       count(*) FILTER (WHERE r.parent_id IS NULL)
  FROM resource_node r
 WHERE r.tenant_id=1 AND r.kind IN ('incubator','storage','transfer_point')
   AND r.attr->>'equipment_instance_id' IS NOT NULL
 GROUP BY 1 ORDER BY 2 DESC;
```
