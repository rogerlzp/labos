## 四、P1 严重级

### P1-1 「阈值只许涨」无任何强制机制，实为纪律而非机制

**位置**：评审包 `01-本轮交付清单与验证.md:19`（及英文 `01-deliverables-and-verification.md:22`）将其写为门禁加固的核心机制；`scripts/ci-gate.sh:41` 仅有注释「阈值：只许涨不许跌」。

**实测**：`grep -rn "MIN_\|只许涨\|threshold" scripts/ .githooks/ scripts/verify-en-docs.py`（排除 `ci-gate.sh` 自身）**零命中** —— 全仓**没有任何一处**校验 `MIN_*` 相对历史只增不减。

**影响**：把 `MIN_PURE=624` 改成 `MIN_PURE=500` 不会被任何检查拦下，CI 照绿。这是评审问题 6（「阈值只许涨是否足够？有没有空子」）的**直接答案：有**。

**要求**：在 `ci-gate.sh` 前置加一段，用 `git show HEAD~N:scripts/ci-gate.sh` 解析旧 `MIN_*`，任一值下降即红灯；使「只许涨」从纪律变为机制。

### P1-2 SKIP 分支 fail-open：「没跑」被算成「绿」

**位置**：`scripts/ci-gate.sh:113`、`:130`、`:155`、`:213`、`:254`（5 处 SKIP 分支）；汇总分支 `:367`；`.githooks/pre-push:22`。

**实测**：5 处 SKIP 分支**只 `echo "跳过..."`，既不计入 `FAIL` 也不打 `pass`**。因此仿真机未启动时 4.7 整段跳过，门禁仍打印「门禁通过」。

**与文档冲突**：`.githooks/pre-push:22` 明写「缺环境的小节会 SKIP，**不静默算通过**」—— 该表述与代码行为**不符**。

**影响**：这是评审问题 4（「跳过分支是否会掩盖真失败」）的**答案：会**。推送时若仿真机未起，要库的关键段全部 SKIP，门禁仍绿 —— 即「门禁通过但关键路径没跑」。

**要求**：SKIP 时打明确 `skip` 记录并在末尾汇总「N 段跳过」，使「全绿」与「有跳过」在输出上可区分；并按实际行为改写 `pre-push` 那句注释。

## 五、P2 一般级

### P2-1 崩溃恢复未覆盖 `queued`/`pending` 僵尸分支与 `paused` 扣留态

**位置**：`scripts/verify-s3-2-residuals.py`（31 条断言）；真实逻辑见 `StartupRecovery.java:46-64`。

**实测**：`StartupRecovery.settle` 的扫描条件为

```
r.status = 'running'
 OR (r.status IN ('queued','pending') AND r.created_at < now() - interval '1 hour')
```

- **`queued`/`pending` 僵尸分支**：`grep -rn "1 hour" labos-kernel/src/test/ scripts/` **零命中** —— L2 自测与端到端**均无覆盖**。崩溃时正排队/等待的记录，超过 1 小时才被收，这条逻辑没有任何断言钉住。
- **`paused`（现场扣留态）**：`StartupRecovery.java:219` 明写 `paused` 是现场扣留态、**留给调度器/人工处置，不能被兜底 settle 误杀**。端到端只造了 `running` 与 `completed` 两种 run，**无 `paused` 断言**。这是「误杀正在被人处置的单子」的高危语义。

**要求**：补两条断言 —— (a) `paused` run 在重启后保持 `paused` 不变；(b) `queued` 且 `created_at` 超过 1 小时的 run 被收成 `failed`。

### P2-2 L2 连库层（1005）无任何阈值保护

**位置**：`docs/测试用例总表.md:22`（记「L1+L2 带库 1005」）；`scripts/ci-gate.sh:67` 是 `test-all.sh` 的**唯一**调用点，且带 `--pure-only`。

**实测**：`grep -rn "test-all.sh" scripts/ .githooks/ .github/` → 仅 `ci-gate.sh:67`（`--pure-only`）。**没有任何 gate 跑连库全量**。因此 L2 的 381 条（1005 − 624）用例数涨了跌了门禁**完全无感**。

**要求**：台账该行标注「不在门禁内（`ci-gate.sh` 只跑 `--pure-only`）」，避免读者误以为 1005 受阈值保护。这是评审问题 6「空子」的第二个实例。
