## 2. Owner 裁定的关键决策（接手 AI 不要改回去）

1. **心跳自动恢复是正确行为**：网络闪断→离线→用到才暂停→恢复在线自动继续。**不要**再用 `needs_manual_recovery` 之类标志掐断心跳自动恢复。
2. **手动恢复可绕过重取证**：`isRecovered` 是可选辅助（操作员可调它看搅拌是否修好），**不强制**接进 resume 门禁。
3. **L3 保持 fail-closed + 路径粒度豁免**：不做全局 fail-open。未配置分区集且未豁免的路径拒绝（`EC-INTERLOCK-RAIL`）。
4. **配置是物理布局，客户现场提供**：我写种子/预检脚本框架，不编真实分区映射/搅拌配对。
