## 四、阅读口径提醒（重要）

- **S-04-B 之后**：实验级 Pause API 返回 `status=accepted` + `controlState=PAUSE_REQUESTED`，
  **不再立即写 paused**；只有设备动作到边界、执行器 settle / 调度器收敛后才写 `paused`。
- **「三层 paused」是 legacy 证据链**：run / experiment_run / experiment 三层都 paused 曾是
  M-01 兼容判据；新用例（4.17 / 4.20）已按「受理 → 设备收敛 → Workflow 边界 → 实验级 paused」
  的顺序断言，不再把「三层立即 paused」当验收。
- **数值不要抄文档**：段数、阈值、用例数只认 `scripts/ci-gate.sh` 的 `MIN_*`；
  历史文档里写死的数字会漂移。
- **故障范围**：ADR-FAULT-SCOPE-002 要求「同一实验内任一 Workcell 故障 ⇒ 整实验停止」，
  该项（N-10 / P-03 完整项）**仍未完成**；当前只有 V1 全局闸门 + 串行执行的部分保证。
