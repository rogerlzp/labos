## 3. 缺的是什么（不是更多 ADR）

建议补**一份**《运行场景与处理规格》，每个场景固定 7 个字段，全文唯一，其它文档只引用场景 ID：

```
场景 ID / 触发条件 / 前置事实（Hold·节点·命令·资源）
→ 门禁判定（CLEAR / HELD / UNKNOWN）
→ 系统动作与写库（哪张表、哪个事务、哪些事件）
→ 失败与 UNKNOWN 分支（超时·断连·崩溃·乱序·重复）
→ 恢复条件与所需证据（人工确认·设备自检·联锁复位·物理核验）
→ 对应测试 ID 与 HIL 证据
```

**前置条件**：写规格前必须先解决 `S-04` 判据冲突，否则规格里的「期望状态」会自相矛盾（一边要求「三层都 paused」，一边要求「未收敛不得显示 PAUSED」）。
