# 文档索引（docs/architecture/）

本目录是**架构决策、状态真源与专项规格**的归档地，共 **25 份**（含本索引）。
按用途分组，先看"决策与状态真源"那两份。

> **怎么用这份索引**：要找"为什么这么设计" → §一；找"现在做到哪了" → §一；
> 找"某个专题的完整规格" → §二～§五。
>
> **文档写的是当时的事实**：代码后来变了，**以代码与测试证据为准**；
> 本目录的文档只在对应章节写明"以 `REMEDIATION_STATUS.md` 和实际代码为准"。
> 英文版目前只覆盖模块地图（`docs/en/architecture.md`），本目录中文文档暂无英文版
> （见 `docs/en/INDEX.md` §3b）。
