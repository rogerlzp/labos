# 封膜机 S100

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 型号 | S100 封膜机 |
| 手册 | `S100封膜机通信接口说明 .docx` |
| 通讯 | **串口，波特率 115200，无校验，1 位停止位** |
| 型号库 | `s100`（`DeviceModels`，依据等级 `MANUAL`） |
| 模拟器 | `--model s100`（带时序约束：托盘原点、板型 1–8、故障锁存） |

## 2. 帧格式

固定 12 字节：

| 位置 | 1 | 2 | 3 | 4 | 5–10 | 11 | 12 |
|---|---|---|---|---|---|---|---|
| 内容 | 报头 | 指令码 | 索引 | 预留 | 数据（**低字节在前**） | 预留 | 预留 |

- 上位机 → 设备：报头 **`0xAA`**，报尾 **`0xFF`**
- 设备 → 上位机：应答 **`0xAC`**，错误 **`0xEE`**
- 错误帧**只有第 5 字节是识别字节**，第 6–8 字节是无效数据（但要求记录）

## 3. 指令集

| 指令码 | 索引 | 数据 | 含义 | 型号库里的方法名 |
|---|---|---|---|---|
| `0x00` | 参数索引 | 参数值 | 设置参数 | `SetParam` |
| `0x01` | 参数索引 | — | 读参数（回 `ac 01 …`） | `ReadParam` |
| `0x02` | — | — | 永久存储参数（不存则断电丢失） | `SaveParam` |
| `0x03` | — | — | 打印所有参数 | `PrintParams` |
| **`0x04`** | — | — | **封膜一次**：`aa 04 00 00 00 00 00 00 00 00 00 ff` | `Seal` |
| `0x04` | `0xA5` | 板型 1–8 | 封膜并改孔板类型 | `SealWithPlateType` |
| `0x04` | `0x5A` | — | 查询孔板类型（回 `ac 04 5a 00 08 …`） | `QueryPlateType` |
| `0x05` | — | — | 复位 | `Reset` |
| `0x06` | — | — | 清除故障标识 | `ClearFault` |
| `0x07` | `0x08` | — | 查询版本 | `GetVersion` |
| `0x0C` | — | 托盘 Y 轴绝对位置（0=回原点） | 托盘移动 | `MoveTray` |

**托盘移动示例**（移到 10000）：
```
aa 0c 00 00 10 27 00 00 00 00 00 ff
        └─ 10 27 = 0x2710 = 10000（低字节在前）
```

> `0x04` 是**一条指令码挂三种用法**，靠索引字节区分（`0x00` / `0xA5` / `0x5A`）。
> 型号库里登记成三个方法名，是因为适配层必须知道要填哪个索引，而不是因为设备有三条指令。

## 4. 错误码（`0xEE` 报头，第 5 字节是识别字节）

**手册共 14 个**（不是 15 个；`0x0D`、`0x0F` 不存在，别自己补）。

| 设备码 | 含义 | 中控码 | 处置 | 严重度 | 该重试还是该叫人 |
|---|---|---|---|---|---|
| `0x80000001` | 信号量溢出 | `EC-08-4001` | RETRY | warn | 自动重试 3 次 |
| `0x80000002` | 错误消息类型 | `EC-08-4002` | ABORT | fatal | 协议版本不符，重试无用 |
| `0x80000003` | 参数范围有误 | `EC-08-4003` | FIX_PARAM | error | 改参数（板型 1–8） |
| `0x80000004` | CAN 通信错误 | `EC-08-4004` | RETRY | warn | 重试 2 次，持续则查线 |
| `0x80000005` | **电机堵转** | `EC-08-4005` | MANUAL | error | **人工排查，排除后关机重启** |
| `0x80000006` | 未检测到孔板 | `EC-08-4006` | MANUAL | error | **叫人上板 + 清故障** |
| `0x80000007` | **刀片脱落** | `EC-08-4007` | MANUAL | error | **进刀换刀片后重启** |
| `0x80000008` | 收到错误指令 | `EC-08-4008` | ABORT | fatal | 指令/索引不支持，核对版本 |
| `0x80000009` | 数值错误 | `EC-08-4009` | FIX_PARAM | error | 检查位置/板型数值 |
| `0x8000000A` | 存储参数出错 | `EC-08-400A` | MANUAL | error | 人工确认后重新存参数 |
| `0x8000000B` | 传感器失效 | `EC-08-400B` | MANUAL | error | 查原点/到位信号 |
| `0x8000000C` | **无纸** | `EC-08-400C` | MANUAL | error | **换耗材**（新卷仍报错 → 弯折从动轮固定金属片） |
| `0x8000000E` | 事件等待超时 | `EC-08-400E` | RETRY | warn | 自动重试 3 次 |
| `0x8000001A` | **托盘不在原点，无法封膜** | `EC-08-401A` | FIX_PARAM | error | **先发 `0x0C` 回原点** |

### 中控怎么用这张表

```
设备回 0x8000000C
  → TcpDriverAdapter 解析回包
  → DeviceErrorMapper 查型号库：EC-08-400C / MANUAL / 严重度 error
  → recovery_policy（库里，scope=node）→ MANUAL
  → 告警正文带"更换耗材；新卷装上仍报错时弯折从动轮固定金属片"
```

三件事值得注意：

1. **编号是反推友好的**：`EC-08-40` + 手册码低字节 = `0x8000000C` ↔ `EC-08-400C`。
   运维看到中控码能直接反推设备码，不用翻表。
2. **没登记的码不会静默**：统一 `EC-08-9001`（转人工），原始码写进
   `device_raw_response` 和 message，事后补登记即可。
3. **改处置不用改代码**：`recovery_policy` 在库里，现场想少重试几次直接 UPDATE。

> 完整链路与"加一台设备五步"见 [`型号库与错误码映射.md`](型号库与错误码映射.md)。

## 5. 模拟器（`--model s100`）

**已实现**（`sim/S100Behavior.java`）：

| 真实行为 | 模拟器表现 |
|---|---|
| 托盘不在原点不能封膜 | `MoveTray(10000)` 后 `Seal` → 回 `0x8000001A` |
| 板型只有 1–8 | `SealWithType(9)` → 回 `0x80000003` |
| 不认识的指令码 | 回 `0x80000008`（型号库外的指令由中控侧 `EC-06-0004` 先拦） |
| 故障**锁存** | 报 `0x8000000C` 后，不清故障再封膜仍报同一个码 |
| 清除故障 | `ClearFault` 解锁；`Reset` 同时回原点 |
| 参数设置/读取 | `SetParam(index,value)` → `ReadParam(index)` 能读回 |
| 复位 | `Reset` 回原点 + 解除故障 |

**与真实设备的差异（必须知道）**：

| 我们的 | 真实的 | 影响 |
|---|---|---|
| JSON `{"method":"Seal"}` | 二进制 12 字节帧 | 协议适配层（.NET sidecar / 串口）要自己拼帧 |
| `Seal` 无参数 | 参数必须先用 `0x00` 设好 | 流程里要先 `SetParam`，不能指望 `Seal(165, 3.5)` |
| 封膜固定 12 秒 | 手册没写实际耗时 | 先用 12 秒，现场实测后改 `DeviceModels` 里的 `delayMs` |
| `"value":10000` | 低字节在前 6 字节 | 适配层负责字节序 |

**怎么用它抓流程缺陷**：

```bash
# 起模拟器
java -cp out com.labos.kernel.sim.SimulatorApp --model s100 --device 501 --port 19501

# 或者命令行 + 定时故障（每 3 条动作失败一次，回无纸）
java -cp out com.labos.kernel.sim.DeviceSimulator --model s100 --port 19501 --fail 3 --fail-code 0x8000000C

# 只在封膜上失败，前 5 条正常 —— 模拟"跑一半没纸了"
java -cp out com.labos.kernel.sim.DeviceSimulator --model s100 --port 19501 \
     --fail 1 --fail-method Seal --fail-code 0x8000000C --fail-from 6
```

GUI 里还有：**制造故障**（下拉选手册上的码）、**清除故障**、**托盘移到 10000**。

## 6. 未解问题

- **参数索引表**（`0x00`/`0x01` 的"参数索引"具体对应什么）—— 手册没列表。
  模拟器只做"存进去/读出来"，不解释索引含义。
- **封膜一次需要多久** —— 决定中控超时设多少。当前按 12 秒。
- **上电后是否需要先复位**（`0x05`）—— 手册没写。
- **断电时正在封膜，恢复后托盘停在哪** —— 手册没写。
  ⇒ 保守做法：断电恢复后先 `Reset` + `MoveTray(0)`，再封膜。
- **托盘位置的有效范围** —— 手册只给了 10000 这个例子，模拟器不校验上限。
