## 1. 这台机器是什么

磁珠法核酸提取的**转盘式**设备。文档原文定义五个轴：

| 轴 | 名称 | 作用 |
|---|---|---|
| X | 转盘 | 把目标板位转到磁套/磁棒下方 |
| Z | 磁套轴 | 升降磁套（套在深孔板里） |
| M | 磁棒轴 | 升降磁棒（进出磁套，实现磁化/去磁化） |
| H | 加热 | 深孔板加热（温度 + 时间） |
| S | 挡板 | 挡板开合 |

完成 **9 个逻辑动作**：

| 编号 | 动作 | 文档 § | 说明 |
|---|---|---|---|
| 0 | 结合 | 1.3 | 转位 → 开加热 → 去磁化（Z 降 M 升）→ 振荡 → 磁套停液面延时 → 磁化（磁棒进磁套）→ 静置 |
| 1 | 洗脱 | 1.3 | 同"结合"的时序，参数不同 |
| 2 | 丢磁珠 | 1.4 | 转位 → 去磁化 → 振荡 → 磁套退液面 → 静置 |
| 3 | 取磁珠 | 1.5 | 转位 → 磁化（磁棒进磁套）→ 下降 → 停留 → 上升 → 静置 |
| 4 | 孵育 | 1.6 | 转位 → Z 降（磁套进液面）→ 振荡 → 退出 → 静置 |
| 5 | 漂洗 | 1.7 | 同"结合/洗脱"族（去磁化 → 振荡 → 磁化 → 静置） |
| 6 | 取磁套 | 1.1 | 转位 → Z/M 配合下降取磁套 → 回原点 |
| 7 | 卸磁套 | 1.2 | 转位 → Z/M 配合下降卸磁套 → 回原点 |
| 8 | 换板位 | 1.8 | 只做 X 轴转位 |

**这台机器是"分段自驱"型**：一条命令下去，设备自己把整个动作跑完（含加热/振荡/静置），上位机只等最终回包。这与"上位机逐步下发 Z/M 动作"的机型不同 —— **中控侧的超时必须按动作真实时长算**，不能用一个 30 s 的默认值。

## 3. 帧格式

文档 §3.1 原文（小端模式）：

| 字段 | 长度 | 值 / 说明 |
|---|---|---|
| SOF | 2 B | 固定 `0xFA 0xFB` |
| Command | 1 B | 命令码（本设备只用 `0x00`） |
| Data_Length | 2 B | 数据段长度（= 25，小端） |
| Data | N B | 数据段（D0…D24） |
| Checksum | 1 B | `Command + Data_Length + Data` 全部字节之和，**取低 8 位** |

- 校验和只覆盖 Command 起的部分，**不含 SOF**。
- 数据段 25 字节，一帧共 2+1+2+25+1 = **31 字节**。
- 数据段内多字节字段（如加热温度、加热时间）同样是**小端**（低字节在前）。

### 4.1 体积索引（§3.3）

文档写"液体体积分 9 种，50mL…800mL"，按步长 100 推断为：

| 索引 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 体积 | 50 | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 |

> ⚠ **单位存疑**：磁珠法提取的处理体积通常是 **µL** 量级（深孔板单孔 ≤ 2 mL），不是 mL。整理时按文档原样记录，接真机前必须与厂商确认（若真是 mL，则这套参数只适用于大体积提取）。

### 4.2 加热模式（§3.4）

| 值 | 含义 |
|---|---|
| 0 | 磁套在深孔板内加热 |
| 1 | 磁套在深孔板外加热 |
| 2 | 加热同时执行后续振荡动作 |

## 5. 文档没写的东西（必须现场确认）

| # | 缺什么 | 影响 |
|---|---|---|
| 1 | **无错误码表** | 文档只定义了正常帧，没定义故障帧。中控只能有适配层码（通讯超时/参数越界），拿不到厂商码 —— 现场排障只能靠日志 |
| 2 | **无应答帧格式** | 只说了"设备执行完回包"，没给回包字节布局。当前按"同帧格式回显 Command + 结果字节"实现，属于**推断** |
| 3 | 体积单位（mL/µL） | 见 §4.1，直接影响参数合法性判断 |
| 4 | 板位到底是"2 个"还是"0/1 表示内外圈" | D1 只有 0–1 两个值，与"双工位（外部交换位 + 内部操作位）"的物理形态一致，但没有明确说明 |
| 5 | 单动作超时 | 结合/洗脱含加热 + 振荡 + 静置，最长可达数分钟（按 D4/D12/D16 参数）；文档没给上限 |
| 6 | 通讯异常重试语义 | 动作类命令超时后能否重发，文档未写 ⇒ 中控按"不自动重发"处理（可能重复动作） |

### 6.3 模拟器要验的物理约束

1. **板位只能 0/1** —— 越界按参数错误拒绝（否则现场配错板位会静默跑到别的板上）。
2. **磁套必须先取（6）才能做结合/洗脱/漂洗/孵育** —— 没磁套就振荡 = 空振，是真实会撞的流程缺陷。
3. **磁套取了没卸（7）不能换板位（8）** —— 磁套跟着转盘走会撞板。
4. **体积索引只能 0–8**；加热温度 0–99；加热时间/停留/振荡/磁化时间 ≤ 9999；振荡幅度 0–2、频率 0–4、模式 0–1、磁套高度 0–5；磁化位置 0–2、模式 0–1、**循环次数 1–10**（0 非法，与取值范围一致）。
5. **动作不能并发** —— 上一条动作没回包前再下发，按"设备忙"拒绝。
