# 现场确认清单（手册没写、但接真机前必须问清楚的）

> **这份清单存在的原因**：两台设备的手册都是"能发什么指令"的说明，
> 但**不写"多久算超时""断电后停在哪""两个值单位是什么"**。
> 这些空档只能现场测，不能编 —— 编错了的表现是"仿真全绿、现场天天报警"。
>
> 每项都写了：**怎么测 / 通过标准 / 猜错了会怎样**。
> 测完把结论写进 `DeviceModels`（参数）或本节（结论），并把 ⬜ 改成 ✅。

---

## 一、S100 封膜机

### 1.1 封膜一次到底多久 ⬜

- **怎么测**：手动触发一次封膜，掐表从"发指令"到"回 `ac 04 …`"。
- **通过标准**：测 10 次，取 **最大值 × 1.5**。
- **现在用的值**：`DeviceModels` 里 `Seal` / `SealWithType` 的 `delayMs = 12000`（12 秒，猜的）。
- **猜错了会怎样**：
  - 猜小 → 中控超时 → 判失败 → 触发重试 → **重复封膜**（膜被压两次，可能废板）；
  - 猜大 → 白等，产线节拍变慢。

### 1.2 参数索引表（`0x00`/`0x01` 的"参数索引"对应什么）⬜

- **怎么测**：`0x03`（打印所有参数）能打出一份"索引 → 值"的清单，抄下来。
- **通过标准**：能对应出 温度、时间、压力 这类常用参数的索引。
- **现在用的值**：模拟器只做"存进去/读出来"，**不解释索引含义**；流程里不能写 `SetParam(17, 180)` 这种猜的。
- **猜错了会怎样**：设错参数 → 封膜温度/时间不对 → 膜封不上，而且**设备不报错**（最难查的一类）。

### 1.3 上电后是否需要先发 `0x05`（复位）⬜

- **怎么测**：断电 → 上电 → 不发复位直接封膜，看回什么。
- **通过标准**：能封膜 = 不需要先复位；回 `0x8000001A`/`0x80000009` = 必须复位。
- **保守做法（当前）**：流程里上电后一律先 `Reset` + `MoveTray(0)`。

### 1.4 断电时正在封膜，恢复后托盘停在哪 ⬜

- **怎么测**：封膜过程中拔电，重新上电后读 `0x04 0x5A`（查板型）或直接 `MoveTray(0)` 看有没有异响。
- **通过标准**：能安全回原点。
- **保守做法（当前）**：恢复后先 `Reset` + `MoveTray(0)`，再封膜。

### 1.5 托盘位置的有效范围 ⬜

- **手册只给了 10000 这一个例子**。
- **怎么测**：从 0 逐步加到设备报错，记录上下限。
- **猜错了会怎样**：超程 → `0x80000005` 电机堵转 或 `0x80000009` 数值错误。

### 1.6 错误帧的第 6–8 字节到底是什么 ⬜

- 手册说"只有第 5 字节是识别字节，但是第 6、7、8 位也要记录，那是无效数据"。
- **怎么测**：抓 3 次同类错误的原始帧，对比第 6–8 字节是否固定。
- **为什么重要**：如果其实是子码，将来可以细分（比如"无纸"分"缺纸/卡纸"）。

## 二、ASpin 2K 离心机

### 2.1 `byCentriRamp`（加速度）的单位和范围 ⬜

- 手册示例是 `byCentriRamp="150"`，没写单位（rpm/s？档位？）。
- **怎么测**：用 100 / 150 / 200 各跑一次，听加速时间或用 `CurrSpeed` 采样。
- **猜错了会怎样**：加速度过大会把细胞甩碎 —— **这条对样本有破坏性，必须问厂商**。

### 2.2 离心过程中能不能开盖（安全互锁）⬜

- **手册没写**。模拟器按"拒绝"处理（回 `EC-06-0006`）。
- **怎么测**：低速（500rpm）运行时发 `ControlCover(1)`。
- **通过标准**：
  - 拒绝 → 中控侧不用做额外保护；
  - **允许** → 中控必须在流程层禁止（这是安全事故，不是小问题）。

### 2.3 `CurrSpeed` / `CurrTime` 的 `nRetValue` 单位 ⬜

- 转速是 rpm 还是 0.1rpm？剩余时间是秒还是分？
- **怎么测**：设 `speed=1500, time=60`，启动后立刻查两条，与设定值对比。
- **猜错了会怎样**：中控判断"离心完成没有"会错（比如把 60 秒当 60 分）。

### 2.4 断电恢复后设备处于什么状态 ⬜

- 门是开还是关？程序继续还是中止？
- **保守做法（当前）**：恢复后先 `Init` 再动作。

### 2.5 多台离心机的模块节点号 ⬜

- 手册的 `CanCfg.ini` 里 `PlateCtri=0x0A,0xE0`。**两台的节点号不能一样**。
- **接第二台时**：改节点号（如 `0x0B`），sidecar 用 `--node` 指定；
  一个 sidecar 进程只对一台，第二台另起一个进程 + 另一个端口。

### 2.6 `SendData` 返回 0 时，`AOutResult` 里的 XML 长什么样 ⬜

- 手册只说"错误在 XML 里"，没给样例。
- **怎么测**：故意发一条错指令（比如 `strCmdName` 写错），把 `AOutResult` 原文存下来。
- **为什么重要**：sidecar 现在只能把整段 XML 塞进错误说明，解析不出结构化错误码。

## 三、中控侧（我们自己要定的）

### 3.1 动作类命令超时怎么配 ✅ 已定

- 型号里 `actionTimeoutMs`（ASpin 2K 是 120 秒）**不是**最终超时；
  最终超时 = `120s + 离心秒数`，由流程节点配置。
- **依据**：手册示例 `WaitForEndOfAction(120000 + time*1000)`。

### 3.2 动作类命令超时后要不要自动重试 ✅ 已定

- **不重试**（`Disposition.MANUAL`）：重复离心会破坏样本，重复封膜会压坏板。
- 只有"瞬时故障"（信号量溢出、通讯抖动）才自动重试。

### 3.3 设备错误码用哪个块 ✅ 已定

- `EC-08-<型号块><手册字节>`：`40`=S100，`41`=ASpin 2K，新型号从 `42` 往后取。
- **理由**：两台机器的 `0x8000000C` 含义可能不同，不能共用一个中控码。

## 四、怎么用这份清单

接一台新设备时：

1. 先抄手册 → 进 `DeviceModels`（指令、错误码、`actionTimeoutMs`）；
2. 手册里**没写的**，全部记到本文件对应小节；
3. 现场按"怎么测"做一遍，把结论写回 `DeviceModels` 的 `delayMs` / `note`；
4. ⬜ 改 ✅，并在 `docs/开发日志.md` 记一条。

> 判断一条信息能不能进代码的标准：**手册写了** → 进；**厂商口头确认** → 进但标在 `note`；
> **我们自己猜的** → 只进 `delayMs` 这类"猜错不致命"的参数，且必须在 `note` 里写明"猜的"。
