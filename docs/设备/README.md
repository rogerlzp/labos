## 三、离心机：一台一台加

离心机不是一个型号。**ASpin 2K 只是第一台**，其余型号在型号库的"待适配清单"里：

```bash
java -cp out com.labos.kernel.sim.DeviceSimulator --list-models
```

| 型号 | 状态 | 缺什么 |
|---|---|---|
| 上海爱翱 ASpin 2K | ✅ 可对接 | — |
| Eppendorf 5810 / 5810 R | ⏳ 待适配 | 通信接口说明 |
| Thermo Multifuge X1/X3 | ⏳ 待适配 | 通信接口说明 |
| Beckman Coulter Allegra X-15R | ⏳ 待适配 | 通信接口说明 |
| 国产全自动离心机（占位） | ⏳ 待适配 | 具体厂商型号 |

**补一台的成本 ≈ 半天**：在 `DeviceModels` 加一条（指令 + 错误码 + 超时）→
必要时加一个 `DeviceBehavior`（时序约束）→ 重生成 SQL → 跑三个自检 → 更新本目录的 md。

详见 [`型号库与错误码映射.md`](型号库与错误码映射.md)。

### 已经对齐的三处（原来对不上）

| 我们的（旧） | 真实的 ASpin 2K | 现状 |
|---|---|---|
| `OpenDoor` / `CloseDoor` | `ControlCover`，**两扇门 A/B** | ✅ `OpenDoorA` / `OpenDoorB` / `CloseDoor` 三个别名 |
| `RunProgram(rpm, minutes)` | `Start(时间, 速度, 加速度)` | ✅ 三个参数，`rpm` 不再用 |
| `GetStatus` | `CurrSpeed` + `CurrTime`（分开查） | ✅ 两条查询；`GetStatus` 标为"手册未提供" |
| `Home` | `Init` | ✅ `Home` → `Init` |
| — | `PcCreateModules`（必须先建模块） | ✅ 已进型号库，模拟器会拒绝"未建模块" |

## 四、真机这一层：sidecar

型号库回答了"这台机器说什么话"，**谁去说**是 sidecar 的事（`sidecar-dotnet/`）：

```
labos-kernel ──TCP──> sidecar ──┬── 串口 12 字节帧    (S100)
                                ├── Cluster.dll+XML  (ASpin 2K)
                                └── 转发模拟器       (工位上没有硬件)
```

中控只认一个端点；换设备只换传输。错误码由中控侧翻译，sidecar 只带回原始码
—— 这样"这个码该转人工还是重试"只有一处定义。

自检：`./scripts/test-sidecar.sh`（起模拟器 + sidecar，按手册时序断言）。

## 五、错误码：设备说的话，中控要听得懂

```
设备 0x8000000C → 型号库查表 → EC-08-400C（MANUAL）
              → recovery_policy（库里）→ 转人工 + 告警带"换耗材"
```

- **设备码 → 中控码**在代码里（跟手册走版本，`DeviceModels`）；
- **怎么处置**在库里（`recovery_policy`，现场可改，不用重启）；
- **没登记的码**统一 `EC-08-9001` 转人工，原始码保留在 `device_raw_response`。

自检：`java -cp out:lib/postgresql-42.7.3.jar com.labos.kernel.driver.DeviceErrorChainSelfTest`

## 六、每类设备文档该写什么

新加设备文档时按这个结构，方便后面的人接着改：

```markdown
# <设备名>（<厂商型号>）

## 1. 基本信息
厂商 / 型号 / 手册版本 / 手册路径 / 型号库 id / 依据等级

## 2. 物理与通讯
串口 or 网口 or CAN；波特率；协议形态（XML / 二进制 / JSON）

## 3. 指令集
| 指令 | 参数 | 含义 | 型号库方法名（别名） |

## 4. 错误码
| 码 | 含义 | 中控码 | 处置 | 该重试还是该人处理 |

## 5. 模拟器如何对齐
已实现 / 与真实设备的差异 / 怎么制造故障

## 6. 未解问题
接真机前必须确认的点
```

## 七、还缺的手册

要让模拟器真的"像"，需要这些设备的**通信接口说明**（不是操作手册）：

- [ ] 离心机：Eppendorf 5810R / Thermo Multifuge X1R / Beckman Allegra X-15R（见第三节）
- [ ] 机械臂（现场是什么牌子？Brooks / KUKA / 其他）
- [ ] 移液工作站
- [ ] 酶标仪
- [ ] 孵育箱
- [ ] 板存储
- [ ] 洗板机 / 分液器
- [ ] 条码扫描

**没有手册时，模拟器只能"形似"**：界面像、参数范围像，
但**指令名和参数含义是猜的**，接现场必改。所以型号库用 `Evidence` 把这件事标出来：
`MANUAL`（可对接）/ `SPEC`（待核对）/ `PLANNED`（只知道型号）。
