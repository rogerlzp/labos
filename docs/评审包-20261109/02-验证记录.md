## 3. 手工 API 验证（本批新增能力）

- **实验/流程暂停受理语义**：Pause API 返回 200 + `status=accepted` + `controlState=PAUSE_REQUESTED`；受理时 DB `experiment_run.status` 仍 running/queued；收敛后 `control_state=NONE`。
- **Handoff**：`PUT /api/experiments/{id}/workcells` 绑定 Workcell；`PUT /handoffs` 配置；`POST /handoffs/confirm` 返回 confirmed 并落 `intervention_record_id` + `manual_window_id`；非法起终点返回 400；`GET /api/handoffs` 可列。
- **Quarantine**：构造 `run.status=quarantined` + 实验 Hold；`GET /api/runs/quarantined` 可见；`POST /api/runs/{id}/quarantine/release` 返回 200，run→failed（`EC-QUARANTINE-CONFIRMED`），Hold 释放，二次同请求 409；页面 `/quarantined` 冒烟通过。
- **人工窗口**：构造 pending `manual_window` → `POST /api/manual-windows/{id}/decide`（MANUAL）返回 `interventionRecordId`；`GET /api/intervention-records` 可查板号/样本/交接点/结果；`/manual-windows` 页面冒烟通过。
- **位置证据**：`POST /api/plate-position-evidence`（MANUAL/SCAN/SENSOR）→ `GET` 可按板号过滤；人工盘点（`locatePlate`）自动落 MANUAL 证据。
- **TransferTransaction**：driver 执行 Transfer 自动建事务；成功回包只到 REPORTED；失败/异常到 UNKNOWN；`POST /api/transfers/{id}/confirm`（SCAN/MANUAL）→ CONFIRMED + position_evidence；重复确认 409。
- **命令 Outbox**：`CommandLedger.begin` 与 command_outbox 同事务；调度器标 DELIVERED；`GET /api/command-outbox` + `POST /api/command-outbox/{id}/replay` 可重置 PENDING 再派发；不重发物理命令。
- **多 Hold**：RuntimeHoldDbSelfTest 14/0：同 scope 不同 kind 可并存、同 kind 幂等、clearKind 精确解除。

## 4. 未验证 / 环境限制

1. **无真机 HIL**：暂停、搬运、隔离均在模拟器/演示库验证；真机停止确认、响应丢失、设备拒绝停止未验。
2. **无真实外部事件总线**：command_outbox/pause_event 只做到「同事务写入 + 调度器标记 DELIVERED + 启动对账」，没有 Kafka/审计中心消费者。
3. **无扫码/传感器硬件**：position_evidence 只有 MANUAL 自动落证；SCAN/SENSOR 仅 API 入口，未接真实设备。
4. **未做多 Kernel 实例/并发压力**：岛锁、Outbox、quarantine 均为单实例语义。
5. **页面只做冒烟**：新页面没有独立 e2e 断言集，主要靠 Playwright 冒烟与 tsc。

## 5. 测试稳定性说明

`test-all` 出现过的偶发红（不同类名、每次不同）已定位为 **API 运行期间与 DB 自测并发写库**；停 API 后同类全量通过。评审时若要复跑，请先停 API，避免把环境并发误判成代码回归。
