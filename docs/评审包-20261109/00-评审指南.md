## 2. 如何拿到环境并跑起来（本地实测路径）

### 2.1 编译内核（无 Maven）

```bash
cd labos-kernel
javac -encoding UTF-8 -d out -cp "out:lib/postgresql-42.7.3.jar" $(find src/main -name '*.java')
javac -encoding UTF-8 -d out -cp "out:lib/postgresql-42.7.3.jar" $(find src/test -name '*.java')
```

### 2.2 数据库 schema

```bash
bash pg_rebuild/schema/merge.sh          # 生成 90_all_in_one.sql
psql -h $LABOS_DB_HOST -U $LABOS_DB_USER -d $LABOS_DB_NAME -f pg_rebuild/schema/90_all_in_one.sql
```

分片迁移现状：`99e`~`99r`（pause_event / command_ledger / command_outbox / pausing / experiment_workcell / experiment_handoff / intervention_record / run quarantine / position_evidence / transfer_transaction / handoff 关联列）。

### 2.3 启动 API（端口 18080）

```bash
cd labos-kernel
java -cp "out:lib/postgresql-42.7.3.jar" com.labos.kernel.api.ApiServer 18080
```

环境变量按现有测试环境设置 `LABOS_DB_HOST/PORT/NAME/USER/PASS`；演示库端口与口令不在本评审包内泄露。

### 2.4 前端（Vite 5173）

```bash
cd webapp
npm run dev
```
