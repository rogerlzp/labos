> ⚠ **2026-11-18 岛切换（照这个点）**：提取线的老岛 `LAB-EXT-01` 已**整岛删除**，
> 现在只剩 `LAB-EXT-02`；**设备编号已改回客户现场编号**：
> `P_AUTO-1..4` / `DISP1..6` / `ARM1` / `STACK1`（建第二个岛时加的 `-02-` 标记已去掉）；
> 流程 `EXT-WORKFLOW-02`（57 节点 / 8 个「等…等待交互」）。
