## 五、评审核对清单（建议逐类勾选）

| # | 维度 | 具体查什么 |
|---|---|---|
| C1 | **并发正确性** | 锁申请顺序是否为固定全序；有无"持有并等待"；TTL 到期与释放竞态；等待图成环判定是否完备（自环/多环/假环） |
| C2 | **事务边界** | `commit()` 是否在正确位置；异常吞掉（`catch (...) {}`）是否导致静默失败；写失败后同事务后续语句是否连带回滚 |
| C3 | **返回值检查** | `executeUpdate()` 返回 0 行是否被当成功；`putPlate`/`notePlateMove`/`tryReserve` 的返回值语义 |
| C4 | **资源泄漏** | JDBC Connection/Statement 是否 try-with-resources；ThreadLocal 是否 finally 清理；线程池是否 shutdown |
| C5 | **幂等与恢复** | 幂等键实现；重启收尾 `StartupRecovery` 是否覆盖全部中间态；状态机是否有不可达/悬挂态 |
| C6 | **安全** | SQL 是否全参数化（拼接）；鉴权开关 `LABOS_AUTH`；有无 `eval`；脚本沙箱边界 |
| C7 | **驱动契约** | 回包字段校验（契约四项）；`method_status` 语义；长连接 `=1` 是否误判失败；超时与重试 |
| C8 | **文档一致性** | 上表 D 编号声明 vs 代码实际；README「已知限制」是否仍成立 |
| C9 | **性能** | 单次命令 6.5 秒开销来源；是否有全表扫描/N+1/缺失索引；大量因子表上的查询 |
| C10 | **可维护性** | 巨型类（`ApiServer`）；两套执行路径（`WorkflowService` vs `ExperimentFlowRunner`）；两套 `long` ID 转换 |
