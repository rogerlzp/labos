**B4 现场联调 checklist 自动化扩展**

## 3. 顺序与依赖（为什么这么排）

1. A1 报表不依赖真机，能立刻产生运营/评审价值，同时为 M10 现场数据定义展示口径；
2. A2/A3 在真机数据大量进来前做，避免文档/门禁提前退化；
3. B 必须等手册；B2 强依赖手册里的忙闲/状态查询指令，不能先写猜测逻辑；
4. C 必须等部署形态/客户需求明确，否则多实例/多租户容易返工；
5. 设备相关 UI 收尾（型号库图标统一、类型中文词表、产线台账明细）跟随 M10 一起做，不单独占轮次。
